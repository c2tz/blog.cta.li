The previous Latin WOFF2 files contained a wght axis from 100 to 700, with
default 400. Both existing CSS @font-face rules expose only weight 400.
These files retain precisely that instance, including the original 228 glyphs
and 228 Unicode mappings in each face. No subsetting or hint removal was used.

Original files are available in Git commit
d80c572522fa2ffa1a9b973e1bf00a33665d1d60 under the same public/fonts paths.
Tools: fonttools 4.64.0, brotli 1.2.0, Python 3.12.

Reproduce each conversion from its original WOFF2 using:
python -m fontTools.varLib.instancer SOURCE.woff2 wght=400 \
  --no-recalc-bounds --no-recalc-timestamp --output OUTPUT.woff2

The output removes fvar, gvar, HVAR and avar variation tables. FontTools sets
the standard OVERLAP_SIMPLE/OVERLAP_COMPOUND flags for static outlines.
Validation compared every decomposed outline and advance against the source
glyph set at wght=400: zero differences across both sets of 228 glyphs.
All glyph hint programs are identical. Compiled cmap, GSUB, hhea, OS/2, gasp
and maxp tables are byte-identical; all hmtx metrics are identical.
Bounding boxes and source timestamps were retained for deterministic output.
